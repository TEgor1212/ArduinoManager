# Скриншоты для документации

Добавьте сюда скриншоты для `README.md` в корне репозитория.

Рекомендуемые имена файлов:
- `workflow-success.png` — успешный запуск workflow CI (job `test`)
- `actions-run.png` — общий список/детали запусков GitHub Actions
- `release-assets.png` — страница GitHub Release с опубликованными бинарниками
- `app-window.png` — окно запущенного приложения Arduino Manager GUI

После добавления файлов убедитесь, что пути в корневом `README.md` указывают на актуальные имена.
